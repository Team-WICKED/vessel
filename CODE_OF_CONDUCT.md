# Community conduct

Vessel's issue tracker and other project spaces should be welcoming and useful
for everyone. Treat people with respect, discuss ideas and behavior rather than
personal characteristics, and provide constructive, specific feedback.
Harassment, threats, discriminatory remarks, and sharing someone else's private
information without permission are unacceptable.

These expectations apply to project interactions, including issues and pull
requests. The repository does not accept code or documentation contributions
from outside Team-WICKED; see [CONTRIBUTING.md](CONTRIBUTING.md).

A confidential contact for reports of conduct concerns has not yet been
published. Team-WICKED needs to establish one and document how reports are
handled. Please do not post sensitive personal information in public issues.
